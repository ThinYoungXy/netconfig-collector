# 设备配置采集器 1.5.1

## 开始使用

1. 解压整个压缩包到有写入权限的目录，双击 NetConfigCollector.exe。无需安装 Python 或 SecureCRT。
2. 点击“新建项目”和“新建区域”，建立所需分区；再点击“导出模板”，或编辑随包 devices.csv。示例地址 192.0.2.x 是文档专用地址，必须替换。
3. 选择项目和区域后点击“导入 CSV”；少量设备也可点“添加设备”。设备信息会自动保存，不需要另存 CSV 才能保留。
4. 点击“登录凭据”，填写 default 组的用户名和密码。不同设备账号不同时，分别创建凭据组，并在 CSV 的 credential 列引用。
5. 选择保存目录，点击“采集当前区域”。每次只采集当前区域。
6. 默认自动信任并保存首次连接的 SSH 主机指纹，不弹确认窗口。如需逐台核对，可取消勾选界面中的“首次连接自动信任并保存 SSH 指纹”。已保存指纹发生变化时仍会拒绝连接。
7. 完成后点击“打开结果目录”。选中设备点击“采集详情”，或双击状态列查看失败原因。

默认并发 4 台、单条命令超时 180 秒；登录提示符等待最多 30 秒。首次现场试用建议每类设备先选 1 台、并发 1，核对结果后再批量采集。
输入账号需要有查看完整运行配置的权限。工具不自动提权，也不自动处理改密、首次登录确认等交互。

## 设备清单

CSV 使用以下表头；支持 UTF-8（推荐带 BOM）及 GB18030 编码：
name,host,platform,port,credential

- name：设备名称。
- host：IPv4、IPv6 或主机名，直接 SSH 可达。
- platform：下表中的完整英文名称，大小写须一致。
- port：默认 22。
- credential：默认 default；密码不放入 CSV。

| platform | 目标设备 | 关闭当前会话分页 | 采集当前运行配置 |
| --- | --- | --- | --- |
| Huawei NE | 华为 NE 路由器 | screen-length 0 temporary | display current-configuration |
| Huawei AR | 华为 AR 路由器 | screen-length 0 temporary | display current-configuration |
| Huawei CE | 华为 CE 交换机 | screen-length 0 temporary | display current-configuration |
| Huawei USG | 华为 USG 防火墙（含 HRP 主备提示符） | screen-length 0 temporary | display current-configuration |
| H3C Comware | H3C Comware 设备 | screen-length disable | display current-configuration |
| Hillstone StoneOS | SG-6000-K1280-A、SG-6000-K5680-A | terminal length 0 | show configuration running |

本版使用上述固定命令，不发送 save、commit、system-view、configure 等配置命令。
关闭分页命令被设备拒绝时，会尝试识别 More 提示并发送空格继续。
山石两个型号使用同一 StoneOS 配置采集流程；并不代表每个固件版本已经验证。

## 输出与结果判定

每次运行建立独立时间戳目录：
- 0001_设备名称_IP.txt：通过检查的配置正文，UTF-8 编码。
- 0001_设备名称_IP.partial.txt：超时、断连、命令被拒绝或校验失败时保留的输出，不能当成完整备份。
- results.csv：成功 / 失败 / 已停止、原因、文件名、SHA-256 摘要；每完成一台更新一次。

“成功”表示读取到已识别的命令回显、原会话提示符和基本配置特征。
华为 / H3C 额外检查 sysname 和末尾 return。山石检查 StoneOS 配置特征与会话提示符；其输出没有统一可靠的文件结束标记。
这不是设备配置可恢复性或业务运行健康的证明。首次应与手工采集内容对比，并核查末尾配置是否完整。

本版仅采集当前运行配置；不下载启动配置、证书文件、许可证或系统镜像，不提供恢复功能。
单台输出上限 32 MiB。中文出现解码错误时会判失败并保留输出，可切换“设备文字编码”后重试。
停止操作不删除已完成文件；建立连接、SSH 认证或发送阶段可能需要等待超时。

## 凭据与文件

登录密码只保存在本次程序内存，不写入设备清单、配置设置或结果日志；退出时丢弃引用。
采集到的设备配置本身可能含密文密码、SNMP 团体字、密钥等敏感信息，本工具不脱敏、不加密配置文件。
请将输出保存到访问受控的位置。

已信任主机密钥位置：
%LOCALAPPDATA%\NetConfigCollector\known_hosts

如提示设备密钥变化，先核实是否设备更换、重装或地址变化；核实后关闭工具，仅移除 known_hosts 中对应设备的旧记录，重连重新核对。
请勿为跳过检查而删除整个文件。

## 常见问题

- 认证失败：检查凭据组、密码、账号权限和设备 SSH AAA 策略。
- SSH 协商失败：本版采用 Paramiko 5.0.0；非常老的 SSH 算法或固件可能不兼容，不自动降低算法安全要求。
- 登录后超时：可能存在改密 / 首次登录交互，或提示符格式不同。华为期望用户视图 <名称>、HRP_M<名称> 或 HRP_S<名称>，H3C 期望 <名称>；山石期望 名称# 或 名称>（含 HA 后缀）。
- 命令被拒绝：检查账号能否手工执行表中的命令，并确认型号和软件版本。
- 输出缺少 return：结果保留为 partial，需检查分页、权限或设备版本。
- 没有结果汇总：检查磁盘空间和写权限，界面会显示汇总写入异常；已保存的单台文件仍可查看。
- 修改设备条目：选中一台设备点击“编辑设备”，或双击设备行（状态列除外）。可修改名称、地址、类型、端口和凭据组。采集期间禁止修改。
- Windows 未知发布者提示：本地构建的 EXE 未购买代码签名证书；可由内部 IT 审核源码和 SHA-256，不建议关闭系统防护。

## v1.3：重试失败设备

采集完成后，点击“重试失败设备”，仅重新采集当前清单中状态为“失败”或“待重试”的设备。
- 成功、待采集、已停止的设备不会包含在失败重试中。
- 失败设备可以先修改类型、地址或凭据组，修改后标为“待重试”；更新登录凭据后也可直接重试。
- 成功设备的状态、详情和已有文件保留。
- 每次重试创建独立 retry_时间戳 目录，内含本次重试配置和 results.csv，不覆盖原始结果。
- 采集详情显示各自文件的完整路径；“打开结果目录”打开最近一次采集或重试目录。
- 进度条和底部完成统计针对本次重试；清单上方统计反映当前全部设备。
- 如无失败设备，会提示无需重试。采集中按钮禁用。
- 状态保存在本次程序会话，关闭程序后不会自动加载上次失败项。

## v1.3.2：SSH 连接诊断

- 每台设备生成同名前缀的 .ssh.jsonl 诊断文件，成功和失败都会保留。
- 区分 TCP、SSH 握手 / 算法协商、主机密钥校验、密码 / 交互式认证、通道、PTY、Shell 与命令读取阶段。
- 日志记录目标地址、阶段、相对耗时、Paramiko 版本和已协商算法；不记录账号、密码、认证提示或配置正文。
- 终端申请和 Shell 请求超过 15 秒会中断并报告具体阶段。
- 日志为逐行 JSON，失败后点击“打开结果目录”，查找对应设备的 .ssh.jsonl。
- 未放宽 SSH 算法、主机密钥校验或修改设备配置。
- 本版用于定位“其他客户端能登录，工具超时”的原因，并不宣称已解决所有客户端兼容问题。

## v1.4.0：项目 / 区域设备库

首次使用：
1. 新建项目，再新建各区域；可通过“管理”重命名默认区域。
2. 为各区域导入 CSV 或手动添加设备，添加 / 编辑 / 删除都会自动保存。
3. 设定当前项目本次登录凭据后，点击“采集当前区域”。

日常使用：
- 重新启动会恢复上次选择的项目、区域和设备。
- 每次启动填写一次当前项目需要的凭据组；同项目切换区域可复用本次凭据。
- 不同项目的本次凭据分开；同名 default 组不会跨项目复用。登录账号和密码均不写入设备库。
- 当前清单非空时，CSV 导入会询问是否替换当前区域；不会影响其他区域。
- 采集中不能切换或管理项目 / 区域。
- 切换区域会清空表格中的本次运行状态；已有采集文件保留。失败重试针对当前区域当前显示的失败项。
- “保存清单”仍可导出当前区域 CSV，用于备份或分享。

结果存放：
保存目录 / 项目名称 / 区域名称 / 时间戳
失败重试保存为同一区域下的 retry_时间戳 子目录。
重命名项目 / 区域影响后续输出路径，不移动已有历史输出。

设备库位置：
%LOCALAPPDATA%\NetConfigCollector\inventory.json
上一版备份：inventory.json.bak
设备库不在 EXE 目录内，升级或重新解压不会清空。
文件损坏时程序会报告错误并保留原文件，不以空库覆盖；可关闭程序后保留损坏文件，再从 .bak 恢复。
检测到另一个窗口修改了设备库时，会拒绝覆盖并提示重新打开。
删除项目 / 区域需确认，且至少保留一个项目、每个项目至少一个区域；已有采集文件不会被删除。
首次安装不会自动读取旧版 CSV，需要按区域导入一次。
